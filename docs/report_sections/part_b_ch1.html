CHAPTER 1: PROFILE OF INSTITUTE


1.1 Introduction to the Institute

The academic framework under which the Real Estate Marketplace Platform was designed, built, and verified was coordinated by the **Gulzar Group of Institutes (GGI), Ludhiana, Punjab**, through the **Department of Computer Science and Engineering**. Gulzar Group of Institutes, affiliated with Punjab Technical University (PTU), Jalandhar, stands as a premier engineering institution in the region. It is dedicated to providing high-quality technical education, fostering innovation, and equipping students with industry-relevant engineering competencies.

GGI’s Department of Computer Science and Engineering emphasizes a curriculum that bridges the gap between classroom theory and professional practice. Coursework covering database management systems, data communication networks, software engineering design patterns, and application security serves as an essential foundation. In the final year of the B.Tech program, students are required to complete a formal software training program and execute an exhaustive capstone engineering project. This requirement challenges students to synthesize theoretical concepts and apply them in unison to construct a functional, secure, and commercially viable software product under faculty supervision and evaluation.

1.2 Training Objectives

The software training and capstone project program established by the CSE department is designed to prepare candidates for the realities of the modern technology industry. The primary objectives of this program include:

1.2.1 Apply the full software development lifecycle to a real project

Students are required to manage the entire Software Development Life Cycle (SDLC). Rather than coding in isolation or developing small, single-file scripts, the project requires:

  • Conducting detailed system analysis and defining clear requirements.
  • Designing database schemas, relationship grids, and API routing structures.
  • Implementing frontends, backend engines, authentication shields, and socket connections.
  • Running functional validation tests, performance benchmarks, and deployment checks.

1.2.2 Build a domain-specific application, not a generic CRUD project

To move away from simplified database tutorials, GGI’s evaluation guidelines state that the project must implement complex business rules, role-based workflows, and real-time interactive systems. The Real Estate Marketplace satisfies this requirement by implementing:

  • A 7-tier numeric role authorization hierarchy guarding backend API endpoints.
  • An administrative moderation panel with status state machines.
  • A side-by-side comparative grid mapping multiple pricing schemas and nine core amenities.
  • A client-side symmetric AES cryptographic chat channel with integrated visit scheduling.

1.2.3 Gain practical confidence with modern development tools

The training aims to build professional proficiency in a modern, production-ready JavaScript-centric ecosystem. Candidates are challenged to master Next.js 16’s App Router structures, React 19’s interactive hook systems, Express 5’s asynchronous routes, and MongoDB Atlas NoSQL engines, preparing them for modern web engineering roles.

1.2.4 Develop professional documentation and software engineering skills

Modern engineering requires generating clear technical specifications. The project challenges candidates to draft complete API routing matrices, MongoDB collection schemas, and system dataflows, ensuring they develop strong documentation and engineering communication skills.
